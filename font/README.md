# مجلد خط ثمانية (Thmanyah Sans)

يرجى وضع ملفات الخط في هذا المجلد بالأسماء التالية:

1. `ThmanyahSans-Regular.woff2` (الوزن العادي: 400)
2. `ThmanyahSans-Bold.woff2` (الوزن العريض: 700)
3. `ThmanyahSans-Black.woff2` (الوزن الأسود / فائق العرض: 900)

*ملاحظة:* يقبل النظام أيضاً امتدادات `.woff` أو `.ttf` (قم بتعديل الامتداد في `src/app/fonts.ts` إذا لزم الأمر).
تم تجهيز إعدادات الخط محلياً في `src/app/fonts.ts` بالكامل، وبمجرد وضع الملفات سيتم تفعيل الخط مباشرة.
