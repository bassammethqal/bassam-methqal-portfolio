## Overview | نظرة عامة

A modern, bilingual (**Arabic RTL / English LTR**) personal portfolio built with **Next.js 15**, **TypeScript**, **Tailwind CSS**, and **Framer Motion**. Designed with a unified **Electric Royal Blue (`#2563EB`)** visual identity, glassmorphic navigation, seamless **Light & Dark Mode**, and **Thmanyah Typography** (`Thmanyah Sans` & `Thmanyah Serif Display`).

موقع شخصي احترافي ثنائي اللغة (**العربية RTL / الإنجليزية LTR**) مبني بأحدث تقنيات الويب الحديثة، يتميز بهوية بصرية موحدة باللون الأزرق الملكي (`#2563EB`)، وشريط تنقل زجاجي (`Glassmorphism`)، ودعم كامل للوضعين **الفاتح والداكن**، مع استخدام منظومة خطوط **ثمانية** الأصيلة.

---

## Key Features | المميزات الرئيسية

- **Bilingual Support (AR / EN)**: Full RTL and LTR layout switching with persistent user preference.
- **Light & Dark Mode**: Instant theme switching with glassmorphic surfaces and high-contrast typography.
- **Thmanyah Type System**: Combines `Thmanyah Serif Display` for editorial headings with `Thmanyah Sans` for clean body text.
- **Continuous Animations**: Perpetual ambient motion, floating portrait frame, and repeatable scroll-triggered transitions.
- **Real Contact Dispatch (`/api/contact`)**: Next.js API route powered by `nodemailer` for Gmail SMTP delivery, with instant pre-filled Email & WhatsApp fallback.
- **Projects Showcase**: Interactive visual mockups with direct links for both end-users/players and venue owners, plus GitHub source links.

## Getting Started | التشغيل المحلي

1. **Clone the repository | استنساخ المستودع**
   ```bash
   git clone https://github.com/bassammethqal/bassam-methqal-portfolio.git
   cd bassam-methqal-portfolio
   ```

2. **Install dependencies | تثبيت المكتبات**
   ```bash
   npm install
   ```

3. **Configure environment variables (Optional for Gmail SMTP) | إعداد متغيرات البيئة (اختياري)**
   Create `.env.local`:
   ```env
   GMAIL_USER=bassammethqal7734@gmail.com
   GMAIL_APP_PASSWORD=your_gmail_app_password
   ```

4. **Run the development server | تشغيل خادم التطوير**
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.
